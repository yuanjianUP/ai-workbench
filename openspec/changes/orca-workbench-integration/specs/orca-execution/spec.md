## Purpose

让用户从独立插件使用兼容的 Orca 工作区及 Agent 能力执行和审查任务，并明确报告能力限制、隔离边界以及不可确认的执行结果。

## ADDED Requirements

### Requirement: 插件独立运行
插件 SHALL 可独立启用或停用，不要求修改现有 Orca 程序；所需能力和权限 MUST 在启用时可供用户审阅。

#### Scenario: 插件停用
- **WHEN** 用户停用插件
- **THEN** 插件不再参与任务操作，现有 Orca 功能仍可使用

### Requirement: 用户发起执行
系统 SHALL 允许用户选择可用工作区及 Agent 并发起手动任务执行，记录返回的执行标识；不支持的操作 MUST 明确提示。

#### Scenario: 启动成功
- **WHEN** 用户选择可用工作区和 Agent 并发起任务，Orca 返回终端标识
- **THEN** 系统记录该标识并展示启动结果，不将其视为任务成功

#### Scenario: 宿主不支持操作
- **WHEN** 目标 Orca 缺少所需接口或权限
- **THEN** 系统提示能力不可用，不声称执行成功

### Requirement: 审查与控制
系统 SHALL 展示可获取的日志、结果和代码变更入口，并在支持时提供停止和恢复；无法获取或未确认的内容 MUST 明确标示。

#### Scenario: 停止能力不可用
- **WHEN** 当前执行器或 Orca 不支持确认停止
- **THEN** 系统提示该限制，不显示已停止

### Requirement: 执行隔离
系统 SHALL 为自动执行验证独立工作区、执行目录、凭据和权限边界；验证未通过时 MUST 不启用自动执行。

#### Scenario: 隔离验证失败
- **WHEN** 所需执行隔离不能得到验证
- **THEN** 系统拒绝自动执行并说明原因
